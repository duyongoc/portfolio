# What the room shows, and in what order.
# Edit this file, then:  python3 tools/wallsheet.py   (guide: wall-layout.md)
#
# Walls take a grid, so their covers are named one by one, left to right and
# top to bottom — line breaks are cosmetic, the grid decides where a cover
# lands, and each list has to fit it.
#
# Props take a list in the order given, or a rule:
#
#   auto section=RESKIN     every build in that section
#   auto link=Youtube       every build with a link of that kind
#
# The section names are CAT's, in demos/portfolio-shared.js — one that is not
# there stops the bake and lists the ones that are.
#
# A rule is evaluated in the room against live data, so a new build lands on
# the right prop without anyone editing anything. A list is taken as written.
#
# Use the id, not the title: the table at the foot of this file is every build
# there is. Why this order — see PROJECT.md.
